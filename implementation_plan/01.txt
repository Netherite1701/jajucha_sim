FEATURE COMPATIBILITY is the number one consideration for this project. make it compatible with the actual jajucha code.

The standalone build should always show the actual Jajucha driving view as the main screen.
Debug information appears around it or as overlays/panels, but it should never replace the driving view.
So the default layout becomes something like:
┌───────────────────────────────────────────────────────────────┐
│ JAJUCHA SIM                RUNNING   1.0×   Python: CONNECTED │
├───────────────┬───────────────────────────────────────────────┤
│               │                                               │
│ Simulation    │                                               │
│ Vehicle       │                                               │
│ Cameras       │             MAIN DRIVING VIEW                 │
│ Depth         │          third-person / chase cam             │
│ Bridge        │                                               │
│ Events        │                                               │
│ ANN           │                                               │
│ FSM           │                                               │
│               │                                               │
├───────────────┴───────────────────────────────────────────────┤
│ speed=3   steer=-5,-5   14.8 cm/s   tick=18421   184.21 s   │
└───────────────────────────────────────────────────────────────┘

No dedicated physics panel
Remove:
Physics
Suspension
Wheel force
Rigidbody diagnostics

from the normal runtime panel list.
We can still retain low-level physics diagnostics internally for automated tests and troubleshooting, but they don't need a user-facing panel.
So the main runtime panels become:
Simulation
Vehicle
Cameras
Depth
Bridge
Events
ANN
FSM

Later potentially:
Course / Scoring

Main driving camera is permanent
Add a dedicated:
ObserverCamera

separate from the Jajucha sensor cameras.
Hierarchy:
Simulation

│  └─ Sensors

The observer camera is never sent to Python.
It exists only so the user can watch the vehicle.

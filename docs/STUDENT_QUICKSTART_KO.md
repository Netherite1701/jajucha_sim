# 학생용 빠른 사용 설명서

이 문서는 `JajuchaSimulator-2026-Student.zip`을 압축 해제한 뒤 처음 실행하는
학생을 위한 안내서입니다. 학생용 standalone 실행에는 Unity 설치가 필요하지
않습니다.

## 1. 실행

1. ZIP을 원하는 폴더에 압축 해제합니다.
2. `Start-Jajucha.bat` 또는 `JajuchaSimulator.exe`를 실행합니다.
3. Windows SmartScreen이 표시되면 `추가 정보` → `실행`을 누릅니다.
4. 게임 창을 한 번 클릭해 키보드 입력을 활성화합니다.

화면 왼쪽 위의 짙은 남색 창이 통합 대시보드입니다. 창의 헤더를 드래그하면
위치를 옮길 수 있고, `접기`를 누르면 대시보드가 접힙니다. 탭 내용이 길면
탭 내부에서 마우스 휠을 굴려 아래쪽 버튼을 볼 수 있습니다.

## 2. 주행 탭

상단 탭에서 `주행`을 누릅니다.

### 주행 설정

1. `코스 변경`: 예선과 결선 사이를 전환합니다.
2. `모드 변경`: 고정 모드와 매 주행 랜덤 모드를 전환합니다.
3. `종류 변경`: `옐로 플래그 속도`와 `돌발 장애물`을 전환합니다.
4. `후보 변경`: `candidate_1`부터 `candidate_5`까지 전환합니다.

고정 모드에서는 미션 종류와 후보 위치를 직접 선택합니다. 랜덤 모드에서는
주행마다 미션과 후보가 선택되며, 선택 결과와 seed는 `디버그` 탭과 주행 결과에
기록됩니다.

`주행 시작`이 회색으로 비활성화되어 있으면 미션 종류 또는 후보가 아직
설정되지 않은 상태입니다. 네 가지 설정을 바꾼 뒤 다시 확인합니다.

### 출발 신호

- `LAMP 1`, `LAMP 4`, `RELEASE`는 화면에서 신호를 미리 확인하는 디버그 버튼입니다.
- 실제 주행은 `주행 시작`으로 시작합니다.
- 네 개의 적색등이 1.5초 간격으로 켜진 뒤 3~6초의 대기 시간이 있습니다.
- 전체 소등과 부저가 울리기 전 차량을 움직이면 부정 출발입니다.
- `주행 중단`은 현재 주행을 종료합니다.

학생용 standalone 패키지에서 차량을 실제로 조종하려면 Python 브리지 프로그램이
별도로 필요합니다. 키보드 WASD나 방향키는 차량 주행 명령이 아닙니다.

## 3. 관찰 카메라 움직이기

`F3`을 누를 때마다 관찰 카메라가 다음 순서로 바뀝니다.

```text
추적(Chase) → 상단(TopDown) → 자유(Free) → 추적(Chase)
```

- `추적`: 차량 뒤쪽에서 차량을 따라갑니다.
- `상단`: 코스를 위에서 내려다봅니다.
- `자유`: 일반적인 프리플라이 카메라처럼 직접 이동합니다.
  - `W/S` 또는 위/아래 방향키: 앞/뒤 이동
  - `A/D` 또는 왼쪽/오른쪽 방향키: 좌/우 이동
  - `Q/E`: 아래/위 이동 (`Ctrl`도 아래로 이동)
  - `Shift`: 빠른 이동
  - 마우스 오른쪽 버튼을 누른 채 드래그: 시점 회전
  - 마우스 휠: 프리플라이 이동 속도 조절

센서 카메라(왼쪽·중앙·오른쪽) 영상은 `센서` 탭에서 확인합니다. 관찰 카메라를
움직여도 센서 카메라의 장착 위치와 영상은 바뀌지 않습니다.

## 4. 코스 편집 탭

1. `코스 편집` 탭을 누릅니다.
2. `공식 원본 · 읽기 전용`이라고 표시되면 편집할 수 없습니다.
3. `연습용 복사본 만들기`를 누르면 편집 도구가 활성화됩니다.
4. 도구를 선택한 뒤 코스의 빈 공간을 클릭하거나, 터널·경사로처럼 영역을
   사용하는 도구는 마우스로 드래그합니다.

주요 도구:

- `선택`: 오브젝트를 선택하고 인스펙터에서 상태를 확인합니다.
- `도로 칠하기` / `도로 지우기`: 도로 마스크와 판정 마스크를 함께 수정합니다.
- `터널` / `경사로`: 경로 영역을 드래그해 구조물을 배치합니다.
- `장애물` / `출발 신호`: 월드에 실제 오브젝트를 배치합니다.
- `출발점` / `도착점` / `속도 센서 A·B` / `이벤트`: 트리거를 배치합니다.

편집 명령은 다음 키로도 조작할 수 있습니다.

| 키 | 기능 |
|---|---|
| `R` | 선택한 항목 90도 회전 |
| `Delete` 또는 `Backspace` | 선택한 항목 삭제 |
| `WASD` 또는 방향키 | 선택한 항목을 한 칸 이동 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Y` 또는 `Ctrl+Shift+Z` | 다시 실행 |

편집 후에는 다음 순서로 확인합니다.

```text
자동 검증 → 시험 주행 → 시험 주행 종료 → 연습 코스 저장
```

공식 원본에서는 저장 버튼이 동작하지 않습니다. 반드시 연습용 복사본을
만든 뒤 저장합니다.

## 5. 채점·센서·디버그 탭

- `채점`: 현재 점수, 위반 항목, 속도 측정, 이벤트 로그를 확인합니다.
- `센서`: 왼쪽·중앙·오른쪽 카메라와 360도 수평 LiDAR 프리뷰를 확인합니다.
- `디버그`:
  - `일시정지 / 재개`: 시뮬레이션을 멈추거나 다시 실행합니다.
  - `한 스텝 실행`: 일시정지 상태에서 정확히 한 tick 진행합니다.
  - `리셋`: 차량·시간·신호·주행 상태를 시작 상태로 되돌립니다.

## 6. 키보드 요약

| 키 | 기능 |
|---|---|
| `F1` | 보조 디버그 상태 표시줄 표시/숨김 |
| `F2` | 주행 모드와 코스 편집 모드 전환 |
| `F3` | 관찰 카메라 모드 전환 |
| `Space` | 주행 모드에서 일시정지/재개 |
| `.` | 주행 모드에서 일시정지 중 한 tick 실행 |

## 7. 자주 발생하는 문제

- `주행 시작`이 눌리지 않음: 미션 종류와 후보를 먼저 선택합니다.
- 카메라가 움직이지 않음: 게임 창을 클릭한 뒤 `F3`으로 자유 모드에 들어갑니다.
  이동은 `WASD`, 시점 회전은 마우스 오른쪽 버튼 드래그입니다.
- 코스 편집 버튼이 회색임: 공식 코스이므로 `연습용 복사본 만들기`를 먼저 누릅니다.
- 아래쪽 버튼이 안 보임: 현재 탭 안에서 마우스 휠을 아래로 굴립니다.
- 차량이 움직이지 않음: 출발 신호가 `RELEASE`가 될 때까지 기다립니다. 실제
  주행 명령은 Python 브리지에서 전달됩니다.

설정과 연습 코스는 다음 위치에 저장됩니다.

```text
%USERPROFILE%\AppData\LocalLow\DefaultCompany\jajucha-sim
```

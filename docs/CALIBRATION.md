# Jajucha calibration status

The simulator uses centimetres as Unity units.

## Confirmed vehicle dimensions

- Overall width: `17.76 cm` (`177.6 mm`)
- Overall length: `24.5 cm` (`245 mm`)
- Wheelbase: `18.295 cm` (`182.95 mm`, approximate)

These values are in `VehicleConfig` and the authoritative vehicle prefab.

## Provisional values

- Wheel-centre track width: `20 cm` remains the stable WheelCollider tuning value; the physical wheel track is not directly confirmed yet.
- Measured wheelbase is stored separately as `18.295 cm`; the existing WheelCollider model remains tuned at `25 cm` until suspension geometry is recalibrated against the physical chassis.
- Camera array: `10 cm` left-to-right span, `4 cm` mount height, `12 cm` forward offset. The supplied photos contain handwritten annotations without unambiguous endpoints, so these remain provisional.
- Course track width: `39.3 cm` is the measured course width, not the vehicle wheel track.

Camera positions are generated by `CameraSensorSystem` from `CameraConfig`, so replacing the provisional values updates all three camera mounts together.
